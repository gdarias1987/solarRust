# Modern Desktop UI/UX Design

Act as a senior product designer specializing in premium desktop applications.

## Design principles

- Create distinctive, modern interfaces rather than generic dashboards.
- Establish a coherent visual language before implementation.
- Use intentional typography, spacing, contrast and hierarchy.
- Prefer sophisticated dark themes when appropriate.
- Apply restrained use of translucency, glass, blur, shadows and gradients.
- Use subtle animations and meaningful microinteractions.
- Design for Windows and macOS desktop environments.
- Support high-DPI displays and window resizing.
- Maintain accessibility and readable contrast.

## Visual direction

Explore:
- Glass and translucent materials
- Layered surfaces and depth
- Refined gradients
- Soft shadows and subtle highlights
- Minimalist controls
- Elegant navigation
- Contextual panels
- Animated state transitions

Avoid:
- Generic Bootstrap-style layouts
- Random colors and inconsistent spacing
- Excessive glow
- Decorative elements without purpose
- Visual clutter

## Workflow

1. Inspect the existing interface.
2. Propose a coherent design system.
3. Define semantic colors, typography and spacing.
4. Design components and interactive states.
5. Implement through the project's actual UI framework.
6. Validate the rendered result.
7. Iterate to improve visual quality.

## Important

The target framework is Rune, implemented in Rust.
Do not assume HTML, CSS, Tailwind, React or Electron.
Coordinate with the rune-ui skill for implementation.
